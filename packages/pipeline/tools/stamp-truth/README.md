# Ukrainian stamp truth set + independent judge (UT15; ported from Sumrak T80b `e8d7b5d`)

- `truth-set-uk-v1.json` — **frozen** (sha256 `4c908ad8c6343a40313c7b3e05b9684874205aba19fb8db0426acebf36edacd4`), 12 tracks of 12 published Ukrainian packs (`sutinki-content/packs`, read-only; no render), **3,152 boundaries**: class P = 455 pause-edge boundaries (323 start / 132 end; time = audio energy edge, identity = Whisper large-v3 `uk` + CTC), class W = 2,697 word-interior boundaries (1,247 start / 1,450 end; Whisper large-v3 agreeing with the old stamp corrected by its local median offset within 70 ms). Tracks: tall-dog td1/td5, scanning ss1/ss3, edu p5la1i01, ukrexam-lexicon lx01, harbinger hb2, rukavychka rka1p2, it-gets-worse ig1, shattered-life sl1, creepypasta-001 knock, marrow-house mh3. All published tracks are single-voice Mr. Wintrow narrations (no `sentenceVoices` track is published yet): re-measure when a multi-voice pack ships.
- UT15 change vs T80b: on Ukrainian narration Whisper large-v3 word STARTS straddle the preceding pause (median about 400 ms early), so the P-class identity vote accepts a start within `[-900, +150]` ms of the energy onset (`START_STRADDLE_MS` in `build_truth.py`) instead of ±120; the boundary TIME is still the energy edge. Judge = `Systran/faster-whisper-large-v3` (MIT), `language="uk"`.
- Pipeline: `wh_large.py` (judge word times) + `forced_align.py --jobs` (CTC output) -> `build_truth.py` -> `build_truth2.py`; scorers `evalpacks.py`, `pausecheck.py`, `slicecheck.py`, `worklist.py`, and `../bench.ts` (restamp vs truth, with `--seed-step`).
- Env: `SUTINKI_STAMP_TRUTH_ROOT` (workspace root, trailing slash, no default), `SUTINKI_STAMP_TRUTH_WORK` (default `~/.sutinki-tools/stamp-truth-work`), `SUTINKI_JUDGE_WHISPER`. Run with the aligner venv (`~/.sutinki-tools/venv-w2v/bin/python -I`) from a directory that is not the model cache. Whisper word times and aligner outputs are not committed.
- Results and the benchmark table: `Stories/_build/stamp-uk-bakeoff/RESULTS.md`.
