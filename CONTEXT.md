# Sutinki (app monorepo) — Repo Glossary

Repo-local terms for `Sutinki/` (`apps/mobile`, `packages/schema`, `packages/pipeline`). Cross-repo language — pack, story, token, bank item, card, backup snapshot, syncd, the Ukrainian-specific terms — lives in the workspace root `CONTEXT.md`; this file only adds what is specific to how this repo is built and kept current.

## Language

**Fork point**:
`Sumrak@350425a` (ADR-0001): the commit Sutinki forked from, history preserved. Everything Sumrak shipped after it arrives only through `UP` merges, never by cherry-pick or copy.
_Avoid_: "port" for a whole release (a port is one feature; an UP is a release-sized merge)

**UP merge**:
A `git merge` of Sumrak `main` up to a pinned stop commit into an `upNN` branch (ADR-0010; procedure `docs/SUTINKI_UPSTREAM.md`). Conflicts are resolved by the Sutinki-wins / Sumrak-wins rules; migrations are regenerated, not taken; everything new is made Ukrainian before `upNN` lands on `main`.

**`UK_PENDING`**:
The feature-flag map in `apps/mobile/src/config/flags.ts` (created by the first UP that needs it). A `true` entry hides a feature's entry points in release builds while the Ukrainian follow-up UT is open; that UT flips it to `false` and deletes the key. Absent from the tree until UP02.

**`normalizeUk`** (`apps/mobile/src/db/normalize.ts`):
The one matching-layer normalizer (ADR-0004): NFC → lowercase → apostrophe fold → ґ→г fold. Bank dedup, FTS queries, typed-answer folding and ASR word matching all go through it; stored text is never mutated. `foldForAnswer` adds stress-mark stripping and whitespace collapse.
_Avoid_: `normalizeRu`, ё-folding code (Sumrak-only)

**Apostrophe fold** / **ґ/г fold**:
The two Ukrainian-specific rules inside `normalizeUk`. The fold target for the apostrophe is U+02BC (a letter, so FTS5 `unicode61` and `\p{L}` keep «п'ять» one token); the authoring rule is the opposite — the pipeline keeps the author's apostrophe (U+0027) byte-for-byte and rejects drift between sentence and token text.

**`uk` key**:
The Ukrainian-text field and column name (`sentence.uk`, `title.uk`, `sentenceUk`, `uk_*` DB columns) wherever Sumrak says `ru` (ADR-0003). A `ru` key anywhere in Sutinki code or fixtures is a merge residue to fix.

**`UK:` draft line**:
The sentence line of a pipeline draft (`UK:` / `EN:` / `GRAMMAR:` + the token table). The grammar and the Ukrainian grammar-tag canon are `packages/pipeline/docs/AUTHORING.md`.

**Migration collapse**:
Sutinki's history starts at `0000_init` + `0001_fts5-search` (ADR-0003) — Sumrak's twelve migrations folded into the `uk` schema. Further migrations are additive numbered files; an UP never takes a Sumrak `.sql`, it regenerates the delta as the next Sutinki number and proves both a fresh install and an upgrade reach the same `sqlite_master`.

**Fixture pack**:
A small Ukrainian pack under `packages/schema/fixtures/packs/` (stories with a silent-Opus karaoke track, course units, prompts, a three-ending dialogue, a family-track unit) whose **structure** — sentence/token counts, track presence, extras kinds, graph shape — is what tests assert; its content strings are Ukrainian and incidental. Regenerated by `packages/schema/scripts/gen-*.mjs`; the manifest hashes by `gen-fixtures.mjs`. Never published, never imported into a phone's data.

**Intentional Russian input**:
A test line that deliberately feeds Russian or surzhyk text to a guard (russism lint, language check) and is marked `// intentional: Russian input`. The only place Russian letters may appear in `packages/` or `apps/mobile/src`.

**Signature boundary**:
A debug-signed (dev client) and a release-signed install cannot update over each other; switching means export a backup, uninstall, install, restore. The S25 always ends a ticket on the release build.

**Release build**:
The signed, arm64-only sideload APK from `pnpm release:android` (keystore + `SUTINKI_*` env outside every repo). `expo.version` follows the UP sequence (UP01 → 1.3.0 …); `versionCode` strictly increases across every build ever installed on any phone.
